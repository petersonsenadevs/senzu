# front-activation (Senzu)

This skill is the entry point when the project does NOT have the "Front y diseño" (front-end and design) block generated by
`sync.ps1` (that is, when Senzu was installed as a plugin or as global skills). Do this in order:

## Front-end tree (start here)
1. UI task (page, component, layout, theme)? → 1st `ui-ux-pro-max` (design system + pattern + components).
2. Specific effect (marquee, parallax, WebGL hover, blob, gooey, view transitions, microinteraction…)? → `references/effects-catalog.md` (Senzu's own recipes in `references/recipes/`: modern CSS, shapes and SVG, kinetic typography, microinteractions, advanced WebGL, **physics and impact**: falling object, broken screen, intro or loader that shatters, with working demos in `recipes/demos/`); if it is not there: `references/effect-sources.md` (Codrops/CodePen + protocol to turn it into a recipe).
3. Animation? → tree F2 of `skill-router/references/decision-trees.md`.
4. 3D? → tree F3 of the same file. Before implementing any effect, validate its cost with F4.

## 1. Detect the front-end stack (never assume it)
| Evidence | Profile | Search tool `--stack` (in order) |
|---|---|---|
| `senzu/senzu.json` with `frontProfile` | the one it indicates | `frontProfile.stacks` |
| `composer.json` with `inertiajs/inertia-laravel` (+ `vue` in `package.json`) | Laravel + Inertia + Vue 3 | `laravel`, `vue`, `html-tailwind`, `shadcn` |
| `package.json` with `next` | Next.js (App Router) + React | `nextjs`, `react`, `shadcn`, `html-tailwind` |
| `package.json` with `astro` | Astro + React islands | `astro`, `react`, `shadcn`, `html-tailwind` |
| `package.json` with `vue` (without Inertia) | Vue 3 SPA | `vue`, `html-tailwind`, `shadcn` |
| `svelte` / `nuxt` / `angular` / `react-native` / `flutter` | others | the upstream stack with that name |
| Nothing conclusive | ask the user | — |

## 3. The project's design system
If `senzu/design-system/*/MASTER.md` exists, it is the source of truth (and `pages/<page>.md` takes precedence for that page).
If it does not exist, generate it with `ui-ux-pro-max`:
```bash
python3 ${CLAUDE_SKILL_DIR}/../ui-ux-pro-max/scripts/search.py "<producto industria keywords>" --design-system -p "<Proyecto>" --persist -o senzu
# Windows: py -3 ...
```
(As a plugin, the skill lives in `${CLAUDE_PLUGIN_ROOT}/skills/ui-ux-pro-max/`.)

## 4. Hard rules that always apply
Contrast 4.5:1 · hover/focus/active/disabled/loading/empty/error states · 375–1440 px without horizontal scroll ·
`prefers-reduced-motion` · SVG icons (never emojis) · semantic tokens, not loose values · forms with a visible label
and the error next to the field · one H1 per view · images with dimensions and `alt` · real copy.
Delivery checklist: `ui-ux-pro-max/references/pro-rules.md`.
