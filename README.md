# Tráfico de Senzu

Rama de datos, sin código: la escribe cada día `.github/workflows/trafico.yml`
(script `tools/trafico.mjs` en main). `trafico.json` es el histórico acumulado por día; `badge-*.json` son
los endpoints de shields.io del README. Incluye los clones del propio CI y de los builds de la web.
